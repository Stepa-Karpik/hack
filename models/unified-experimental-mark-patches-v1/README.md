# Patch-level signature/seal head v1 (same PaddleOCR-VL backbone)

Небольшая MLP по каждому патчу визуальных признаков той же замороженной PaddleOCR-VL 1.6: признак патча и среднее по соседям 3×3 → подпись и печать. Второй детектор не добавляется: признаки берутся из того же визуального прохода, что и распознавание. Наличие отметки — максимум сглаженной вероятности; рамка — связная область вокруг максимума.

Данные:

- 743 обучающие страницы: 360 новых `marks-v1` (подпись поверх линии над «(подпись)», процедурные печати, негативы), `unified-data-v2` и `unified-real-marks-v1` train;
- подписи Ultralytics (AGPL-3.0), разбиение источника сохранено;
- порог 0,94 и правило «решает патч-голова» выбраны на val.

Ошибки (старая глобальная голова → новая):

| Набор | Подпись | Печать |
| --- | --- | --- |
| Документы организаторов PNG/PDF | 0 → 0 | 0 → 0 |
| Реалистичные бланки, 7 страниц, только оценка | 4 → 0 | 5 → 0 |
| `marks-v1` test, 60 страниц | 22 → 0 | 26 → 1 |
| Прежние test | 0 → 0 | 0 → 0 |

Отчёт: `selection-report.json`. Подлинность подписи и печати не проверяется.
