# Experimental native FP32 language LoRA v5 (natural pages)

Продолжение LoRA v4 на 360 оригинальных вымышленных страницах v5 и 120 страницах повторения v4b. Один проход, 240 шагов, language q/v r8, LR 2e-5 с косинусным спадом, strict FP32/1MP, TF32 выключен. Vision (437 параметров) и голова headv3 заморожены, признаки и оценки совпадают бит в бит.

Результаты относительно v4 — в docs/research.md.

- Документы организаторов: 277→279 PNG, 276→278 PDF. Потерь нет. Отметки 50/50.
- v4b: значения val 279→286, test 282→283; в test потеряно 2 значения.
- Тест на семействах шрифтов, которых не было в обучении: word F1 0,964→0,971.
- Реальные страницы MWS (только проверка): word F1 0,909→0,919, но на ~6 страницах изменился порядок блоков, CER 22,8%→26,0%.
- Известная регрессия: иногда склеиваются короткие пустые строки меток. Локальная страница исправляет это отдельной пробельной обработкой layout v2; исходный ответ модели сохраняется.

Production не заменён. Основа PaddleOCR-VL-1.6 (Apache-2.0) нужна отдельно. Адаптер, код и данные проекта — AGPL-3.0. Контрольные точки 80/160/240 и все отчёты лежат в work/ocr-v5.
