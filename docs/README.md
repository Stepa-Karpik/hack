# Документация Онлайн-деканата

Онлайн-деканат — сервис предварительной проверки студенческих документов и электронной очереди заявок в деканат. Документ (фото, скан или PDF) распознаётся локальными моделями. Сервис извлекает поля, находит подпись и печать, проверяет комплектность по Положению и передаёт заявку сотруднику деканата для решения.

Вся документация одним файлом: [online-dekanat-documentation.pdf](online-dekanat-documentation.pdf).
