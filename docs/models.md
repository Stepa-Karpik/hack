# Модели

В системе девять моделей. Шесть из них — собственные: четыре дообучены на наших данных, две обучены с нуля. Обучающие данные — собственная синтетика с вымышленными людьми и организациями ([training.md](training.md)). Документы организаторов в обучение не входили и используются только для оценки.

| Модель | Движок | Назначение | Происхождение | Размер |
| --- | --- | --- | --- | --- |
| CRAFT `craft_mlt_25k` | Конвейер | Поиск строк текста | EasyOCR, используется как есть | 79 МБ |
| CRNN `cyrillic_g2` | Конвейер | Распознавание строки кириллицы | EasyOCR, используется как есть | 15 МБ |
| `ocr_cyrillic.pt` | Конвейер | Перечитывание цифровых полей | **Дообучена** из `cyrillic_g2` | 15 МБ |
| `ocr_quotes.pt` | Конвейер | Перечитывание названий в кавычках | **Дообучена** из `ocr_cyrillic.pt` | 15 МБ |
| `marks.pt` | Конвейер | Подпись и печать | **Дообучена**: архитектура YOLOv8n от Ultralytics, старт с весов COCO | 6,5 МБ |
| `fields.joblib` | Конвейер | Классификатор подписей полей | **Обучена с нуля** | 0,6 МБ |
| PaddleOCR-VL 1.6 + `unified-experimental-natural-v5` | Цельная модель | Чтение страницы | Базовая модель PaddlePaddle; адаптер LoRA **дообучен** | 1,9 ГБ + 2,5 МБ |
| `unified-experimental-mark-patches-v1` | Цельная модель | Подпись и печать с рамками | **Обучена с нуля** на признаках модели | 1,2 МБ |
| Qwen3.5-4B (`qwen3.5:4b`) | Ассистент | Ответы на вопросы | Qwen, используется как есть через Ollama | 3,3 ГБ |

## Карточки моделей

### `ocr_cyrillic.pt` — распознаватель цифровых полей

| | |
| --- | --- |
| Задача | Распознавание строк с датами, номерами, курсом и кодами групп |
| Основа | EasyOCR `cyrillic_g2` (VGG + BiLSTM + CTC) |
| Обучение | 4000 синтетических фрагментов строк с имитацией съёмки. Свёрточная часть заморожена, обучаются рекуррентные слои и выходной слой |
| Использование | Каскад: перечитывает только сомнительные цифровые поля |
| Отбор | Принят по аудиту разработки: поля 97,2% → 99,2%, полностью верные карточки 83,3% → 94,4% (`models/ocr_selection.json`) |
| Код | `scripts/train_ocr.py`, `scripts/train_official_ocr.py` |

### `ocr_quotes.pt` — распознаватель названий в кавычках

| | |
| --- | --- |
| Задача | Названия вуза и организации, оценка в «ёлочках» |
| Основа | `ocr_cyrillic.pt` с двумя добавленными токенами `«` и `»` |
| Обучение | Синтетические строки с кавычками. LR 2·10⁻⁶ для свёрточной части, 10⁻⁵ для BiLSTM, 10⁻⁴ для выходного слоя |
| Использование | Только если поле не найдено и есть явный контекст: справка об обучении или практике |
| Отбор | 57 → 61 верных значений на отобранных случаях разработки (`models/quote_selection.json`) |
| Код | `scripts/train_quote_ocr.py` |

### `marks.pt` — детектор подписи и печати

| | |
| --- | --- |
| Задача | Детекция двух классов: подпись, печать |
| Архитектура | YOLOv8n (Ultralytics, AGPL-3.0) |
| Обучение | Старт с весов COCO. 383 страницы: реальные подписи из набора Ultralytics Signature и процедурные печати разных форм, 640 px |
| Защита от ложных срабатываний | Слабый кандидат поверх напечатанного «Подпись» отклоняется. Для типов из конструктора отклоняется кандидат на уверенно распознанной строке |
| Код | `scripts/train_detection.py`, `scripts/participantkit/mark_guard.py` |

### `fields.joblib` — классификатор подписей полей

| | |
| --- | --- |
| Задача | Определить, какое поле подписано в начале строки («ФИО студента:», «Дата выдачи») |
| Модель | TF-IDF по символьным 2–5-граммам (до 15 000 признаков) + логистическая регрессия (C = 12, сбалансированные классы) |
| Обучение | 21 802 синтетических префикса с имитацией ошибок OCR |
| Код | `scripts/train_fields.py` |

### Адаптер LoRA `unified-experimental-natural-v5`

| | |
| --- | --- |
| Основа | PaddleOCR-VL 1.6, 905 млн параметров, ревизия `c5630ab…` |
| Модули | `q_proj`, `v_proj` языковой модели; ранг 8, α 16, dropout 0,05 |
| Обучаемых параметров | 626 688 |
| Данные | 360 страниц с естественным текстом, 27 семейств шрифтов, разные подписи полей, плюс 120 страниц повторения |
| Оптимизация | AdamW, LR 2·10⁻⁵, 240 шагов, косинусный спад, seed 42 |
| Время обучения | 28 минут на RTX 3060 Ti |
| Подробно | [model.md](model.md#адаптер-lora-v5-modelsunified-experimental-natural-v5) |

### Патч-голова `unified-experimental-mark-patches-v1`

| | |
| --- | --- |
| Вход | Признак каждого патча vision encoder и среднее его соседей 3×3 (2304 числа) |
| Модель | MLP 2304 → 128 → 2, сглаживание карты 3×3 |
| Решение | Отметка есть, если максимум карты ≥ 0,94. Рамка — связная область вокруг максимума |
| Обучение | 743 страницы: подписи поверх линий, круглые и прямоугольные печати, негативы с «М.П.» без печати. AdamW, 3000 шагов |
| Подробно | [model.md](model.md#патч-голова-v1-modelsunified-experimental-mark-patches-v1) |

### Qwen3.5-4B — ассистент

Используется без дообучения через Ollama. Отвечает в JSON по схеме: вид ответа, текст, поля-источники, пункты Положения. Каждый ответ проверяется на привязку к документу. Подробно: [assistant.md](assistant.md).
